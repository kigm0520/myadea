# myadea

## 냉장고 털이 자판기

집에 있는 재료와 내 주방의 양념·조리도구만으로 한 끼 레시피를 뽑아 주는 웹앱입니다. 앱 화면과 기능은 `index.html` 하나에 들어 있고, 앱으로 설치하는 데 쓰는 파일만 따로 있습니다.

바로 써 보기: https://kigm0520.github.io/myadea/

### 주요 기능

- **재료 투입**: 재료를 쉼표로 구분해 개수 제한 없이 넣거나, 예시 조합과 단골 재료 버튼으로 넣습니다.
- **내 주방 기억**: 갖고 있는 조리도구와 양념을 체크해 두면, 그 안에서만 레시피를 만듭니다.
- **4대 조리 틀 판정**: 재료를 보고 부침, 볶음·덮밥, 찌개, 면·간편식 중 하나를 골라 3단계 레시피와 맛 조절 팁을 보여 줍니다. 다른 조리 틀로 다시 뽑을 수도 있습니다.
  - 넣은 재료와 내 주방 도구로 만들 수 있는 틀만 고릅니다. 달걀·부침가루가 있어야 부침, 냄비가 있어야 찌개, 면이나 밥이 있어야 면·볶음밥이 나오고, 밥을 넣었을 때만 덮밥으로 냅니다.
  - 프라이팬과 냄비가 없으면 전자레인지·에어프라이어·전기포트 조리법으로 바꿉니다.
- **AI 생성과 안전망**: Gemini 키가 있으면 AI로 레시피를 만듭니다. 하루 무료 코인은 5개입니다. 코인을 다 쓰거나 키가 없거나 AI 응답이 실패하면 내장 엔진이 대신 만듭니다.
- **비용 방어**: 같은 조합은 캐시에서 불러와 코인을 쓰지 않습니다. 연속으로 누르지 못하게 쿨타임도 둡니다.
- **도감**: 마음에 드는 레시피를 저장하고 다시 불러옵니다.
- **PWA**: 스마트폰 홈 화면에 앱처럼 설치할 수 있습니다. 처음 접속하면 3단계 사용 가이드가 나옵니다.

모든 데이터는 브라우저(localStorage)에 저장됩니다.

### 실행 방법

로컬 서버로 띄운 뒤 브라우저에서 엽니다. PWA 설치 기능은 `http://` 또는 `https://`로 열어야 동작합니다.

```bash
python3 -m http.server 3065 --bind 127.0.0.1
# 브라우저에서 http://localhost:3065 접속 (이 컴퓨터에서만 열림)
```

간단히 볼 때는 `index.html`을 브라우저로 직접 열어도 됩니다.

### 앱으로 설치하기 (PWA)

`http://localhost:3065`처럼 서버로 연 상태에서만 설치할 수 있습니다. 파일을 직접 열면 설치되지 않습니다.

- **PC 크롬·엣지**: 주소창 오른쪽의 설치 아이콘을 누르거나, 화면 상단 배너의 **앱 설치하기**를 누릅니다.
- **아이폰 사파리**: 공유 버튼 → **홈 화면에 추가**를 누릅니다.

설치에 쓰는 파일은 `manifest.webmanifest`(앱 이름·아이콘), `icons/`(앱 아이콘), `sw.js`(서비스 워커)입니다.

### 필요한 키 이름

키 없이도 내장 엔진으로 동작합니다. 키는 앱 화면 우측 상단의 **클라우드/API** 버튼을 눌러 입력하며, 사용자의 브라우저에만 저장됩니다. 코드나 저장소에는 키 값을 넣지 않습니다.

| 키 이름 | 용도 | 필수 |
|---|---|---|
| Gemini API Key | AI 레시피 생성 (Google AI Studio에서 발급) | 선택 |
| Supabase Project URL | 클라우드 연동 | 선택 |
| Supabase Anon Public Key | 클라우드 연동 | 선택 |
